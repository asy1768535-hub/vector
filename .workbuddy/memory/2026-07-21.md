## 前端开发：Vector KB Console 管理控制台
- 为「向量知识检索底座」项目开发了零构建纯静态响应式管理前端。
- 交付位置：`D:\图片\vector-kb-console\`（用户指定 D 盘图片文件夹）；scratch 源在 `.workbuddy/artifacts/vector-kb-console/`。
- 技术：原生 JS（IIFE 模块，ES5 兼容）+ CSS 变量双主题设计系统，无框架无 CDN，file:// 直开可用。
- 7 个视图：dashboard / libraries / documents / search / import / jobs / settings；hash 路由。
- 关键设计：API 层真实后端优先（/health 探测，15s 缓存），失败回退内置 mock 演示数据；配置存 localStorage（vkb_console_config / vkb_theme / vkb_search_history）。
- 响应式断点 1200/1024/768/480；移动端侧栏抽屉；Alt+1~6 快捷键；骨架屏/空态/错误态/Toast 完整。
- 后端接口约定（与 docs/13 对齐）：/admin/libraries、/libraries/{slug}/documents|query|import-file、/admin/jobs。
- 注意：jobs.js 视图用 `render.call(ctx, ...)` 模式让视图可挂 cleanup（轮询定时器），app.js 路由切换时调用。
