# 知识库检索接口规范与使用说明

## 1. 概述
本文档详细描述向量知识库的语义检索与混合检索接口调用方式。

## 2. 接口端点
- 请求路径：`POST /libraries/{slug}/query`
- 请求格式：`application/json`

### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `query` | string | 是 | 检索关键词或自然语言问题 |
| `limit` | int | 否 | 返回结果条数，默认 5，范围 1~20 |
| `folder_id` | string | 否 | 限定检索特定文件夹及其子目录 |

## 3. 核心能力
1. **语义相似度检索**：通过 BGE 向量模型计算问题与分片的余弦相似度。
2. **混合检索重排**：结合 BM25 全文检索和密集向量检索。
3. **知识图谱关联**：支持实体提取与多跳关系推理。
