# 知识库系统部署与运维指南

## 1. 环境准备
- Node.js 18+ (开发与前端预览)
- Python 3.10+ (后端 API 与任务调度)
- Qdrant 向量数据库
- PostgreSQL 15+ 关系存储

## 2. 本地前端开发预览模式
使用 `?preview=1` 参数启动轻量化预览模式：
```bash
# 启动本地开发服务
python -m http.server 5599
# 访问地址
http://127.0.0.1:5599/?preview=1
```
在该模式下，所有接口由 `preview_mode.js` 自动拦截并模拟，无需运行重型数据库即可修改调试前端。
