# 06 — 验收规则

## 全局验收标准

### 视觉一致性

- [ ] 所有页面使用相同的 CSS 变量（颜色、间距、圆角）
- [ ] 顶栏高度 64px, 位置固定, 所有页面一致
- [ ] 侧栏宽度 224px (展开) / 64px (收起), 折叠动画流畅
- [ ] 页面背景 `#F5F7F8`, 面板/卡片背景 `#FFFFFF`
- [ ] 主色 `#176B57` 用于主按钮、链接、active 指示条
- [ ] 无紫色渐变、装饰圆球、玻璃拟态、3D 效果
- [ ] 圆角不超过 8px
- [ ] 表格表头浅灰背景, 行间细边框

### 功能完整性

- [ ] 14 个页面路由均可访问
- [ ] 登录 → 跳转 Dashboard
- [ ] 401 → 跳转 Login (3s 去抖)
- [ ] 超管可见全部菜单
- [ ] 普通用户菜单按权限过滤
- [ ] 直接访问越权 URL → 跳 Dashboard + warning

### 资源本地化

- [ ] Network 面板无公网请求（unpkg / jsdelivr / iconify / cdnjs / google fonts）
- [ ] 所有图标通过 `<local-icon>` 渲染
- [ ] 所有 JS 依赖在 `vendor/` 目录

### 错误处理

- [ ] 不出现 `[object Object]`
- [ ] 不出现英文错误码
- [ ] 422 数组转为字段级中文提示
- [ ] 网络错误有通用中文回退

### 代码质量

- [ ] `node --check` 所有 JS 文件通过
- [ ] Node 测试全部通过
- [ ] `pytest -q` 通过
- [ ] `ruff check app tests scripts` 通过
- [ ] `python scripts/check_release_safety.py` 通过
- [ ] `git diff --check` 通过

## 浏览器验收

- **分辨率**: 1440×900 (主要), 1920×1080 (验证)
- **浏览器**: Chrome / Edge 最新版
- **检查项**:
  1. Network 面板零公网请求
  2. 登录页正常显示
  3. Dashboard 服务状态正常
  4. Chat 流式问答正常
  5. 主题切换即时生效
  6. 刷新后主题保持
  7. 恶意 Markdown 不执行脚本
  8. 1440×900 下无横向滚动条
