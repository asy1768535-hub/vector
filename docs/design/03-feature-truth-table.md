# 03 — 历史设计功能真实性清单

> 本页保留早期设计取舍，不再作为当前按钮和 API 真相。当前可操作能力以
> [前端按钮功能清单](../48-frontend-button-function-inventory.md) 为准。

对参考设计稿中可能出现的功能逐一核实，标注实现状态。

## 清单

| 功能 | 状态 | 说明 |
|---|---|---|
| 邮箱+密码登录 | ✅ 当前支持 | `/auth/jwt/login`, cookie-based JWT |
| 忘记密码 | ❌ 本版本不做 | 无后端支持, 无邮件服务 |
| 手机号登录 | ❌ 本版本不做 | 无后端支持 |
| 消息中心 | ❌ 本版本不做 | 无后端支持, 不加假按钮 |
| 帮助中心 | ❌ 本版本不做 | 无后端支持, 不加假按钮 |
| 权限申请 | ❌ 本版本不做 | 无审批流程后端 |
| 用户角色管理 | ⚠️ 仅超管标记 | `is_superuser` 布尔值, 无细粒度角色 |
| 角色管理 (RBAC) | ❌ 本版本不做 | 当前 Casbin 按用户-库-动作授权 |
| 用户批量导入 | ❌ 本版本不做 | 无后端支持 |
| 知识库 CRUD | ✅ 当前支持 | 超管在库管理页操作 |
| 文档上传 (多格式) | ✅ 当前支持 | `.txt/.md/.markdown/.rst/.log/.ini/.cfg/.conf/.json/.yaml/.yml/.xml/.html/.htm/.csv/.tsv/.pdf/.docx/.pptx/.xls/.xlsx/.bmp/.jpeg/.jpg/.png/.tif/.tiff/.webp`，队列上传；独立图片需开启库级 OCR |
| 替换已有文档 | ✅ 当前支持 | `replace_document_id` 模式 |
| 文档在线编辑 | ✅ 当前支持 | KnowledgeCatalog.js 内联编辑 |
| 原始文件在线预览 | ❌ 本版本不做 | 已支持受控文件访问/下载，但没有浏览器内联预览器 |
| 向量检索 | ✅ 当前支持 | `/libraries/{slug}/query`, Dense/Hybrid |
| 检索结果导出 | ✅ 当前支持 | 浏览器根据当前结果生成 CSV，不新增后端接口 |
| 智能问答 (RAG) | ✅ 当前支持 | SSE 流式, Markdown 渲染, 引用标注 |
| 聊天附件上传 | ❌ 本版本不做 | Chat 仅文本问答 |
| 会话历史 | ✅ 当前支持 | 按库筛选, 归档/删除, 多轮上下文 |
| FAQ 管理 | ✅ 当前支持 | 库级 FAQ CRUD, 停用/启用 |
| 权限矩阵 | ✅ 当前支持 | 按用户-库授予 read/insert/delete |
| API Key 管理 | ✅ 当前支持 | 创建/吊销, 一次性明文展示 |
| 嵌入任务监控 | ✅ 当前支持 | 状态筛选, 重试, 批量重置 |
| 运行状态监控 | ✅ 当前支持 | heartbeat 聚合, API/Worker/Cleanup |
| 审计日志 | ✅ 当前支持 | 中文摘要, JSON 展开, 搜索过滤 |
| 问答日志 | ✅ 当前支持 | 按库/状态/用户/时间筛选 |
| 上传暂停队列 | ❌ 本版本不做 | 当前仅顺序上传 |
| 上传进度 | ✅ 当前支持 | 显示逐文件上传和后台处理状态 |
| 备份/恢复 | ⚠️ 仅脚本 | PowerShell 模板, 需手动执行 |
| 系统设置页面 | ❌ 本版本不做 | 配置在 `.env` 文件中 |
| 主题切换 | ❌ 本版本不做 | 当前使用单一企业主题，无切换按钮 |
| 暗色模式 | ❌ 本版本不做 | 当前没有暗色主题入口 |
| 响应式 (窄屏) | ⚠️ 部分支持 | 登录页有断点, 主框架未完整适配 |
| 多语言 | ❌ 本版本不做 | 仅简体中文 |

## 状态图例

- ✅ 当前支持 — 后端接口 + 前端页面均已实现
- ⚠️ 部分支持 — 有基础实现但未完整
- ❌ 本版本不做 — 明确不在此版本范围内

## 若效果图出现不支持功能

在设计改造时, 对应区域:
1. 不创建假按钮或假入口
2. 用现有功能的合理布局填充该空间
3. 在设计文档中标记为 "预留区域"（如未来会用到）
