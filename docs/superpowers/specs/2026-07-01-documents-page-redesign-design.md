# 文档页面重构设计

日期：2026-07-01

## 目标

以 `D:\AI_work\job\向量库图片参考\文档.png` 为视觉参考，将现有文档页重构为清晰的企业知识库文档工作台。保持现有全局绿色企业主题、权限规则和后端接口不变。

本次允许增加能够通过纯前端状态或现有 API 完成的按钮。任何需要新增后端端点、响应字段、数据库结构或持久化状态的功能均不实施。

## 已确认范围

- 使用现有全局顶栏和左侧导航，不再改动全局框架。
- 顶部提供知识库选择、核心统计和主要操作。
- 中部提供客户端筛选与重置。
- 底部提供文档表格、客户端分页和详情抽屉。
- 复用现有文本提交、整篇更新、删除、文件导入、文档任务列表和管理员任务重试接口。
- 不实现查看原文、下载原文件、逐文档分片数、服务端全文搜索和版本历史正文。
- 不修改 `app/` 下任何后端代码。

## 页面结构

### 1. 文档概览栏

页面顶部使用一张白色面板，布局参考素材：

- 左侧为知识库选择器。
- 中间为四项统计：
  - 文档总数：`stats.document_count`
  - 处理中：`stats.pending_jobs + stats.processing_jobs`
  - 已完成：`stats.done_jobs`
  - 失败：`stats.failed_jobs`
- 右侧为主要操作：
  - `文件导入`：跳转现有 `/import` 页面，携带当前知识库和 `mode=add`。
  - `提交文本`：打开现有文本提交弹窗。

两个操作都受 `canInsert` 控制。无写入权限时按钮禁用并保留提示。

### 2. 筛选栏

筛选仅作用于当前已加载文档，不新增搜索接口：

- 关键词：匹配标题、`external_id` 和文档 ID。
- 状态：全部、等待中、处理中、完成、失败。
- 更新时间：可选日期范围，使用 `updated_at`。
- 文档类型：根据标题后缀推导 PDF、Word、Excel、Markdown、文本和其他。
- 重置：恢复所有筛选、页码和默认每页数量。
- 刷新：重新加载当前知识库文档与统计。

列表请求使用现有 `limit=500` 上限。若 `stats.document_count > docs.length`，页面显示“当前加载 X / 总计 Y”，避免把客户端分页误解为完整服务端分页。

### 3. 文档表格

列设计：

- 文件名：文件类型色块、标题；无标题时显示 `external_id` 或短 ID。
- 状态：使用中文状态标签。
- 版本：`current_revision`，显示 `vN`。
- external_id：无值显示 `—`。
- 更新时间：格式化 `updated_at`。
- 操作：
  - `详情`：所有可读用户可用。
  - `编辑`：有 insert 权限时可用，复用现有整篇替换弹窗。
  - `重试`：仅超级管理员且文档状态为 failed 时显示。
  - `删除`：有 delete 权限时可用，保留二次确认。

不显示逐文档分片数，因为 `DocumentRead` 没有该字段；不得通过逐行请求任务接口伪造分片数，避免 N+1 请求。

### 4. 客户端分页

- 默认每页 10 条，可切换 10、20、50。
- 筛选条件变化时回到第 1 页。
- 页码只对当前加载的最多 500 条文档生效。
- 当过滤后无数据时展示明确空状态。

## 详情抽屉

点击详情时打开右侧抽屉，立即显示当前行已有字段：

- 标题、文档 ID、external_id
- 状态、版本
- content hash
- 创建时间、更新时间
- metadata 格式化 JSON
- last_error

同时调用现有 `api.listDocumentJobs(slug, documentId)` 加载摄入任务，按现有返回顺序展示：

- 任务状态
- 创建、开始、结束时间
- 重试次数或 attempt 字段（仅当返回存在）
- error_message（仅失败时）

失败任务的“重试”仅对超级管理员显示，调用现有 `api.retryJob(job.id)`。成功后重新加载该文档任务、文档列表和统计。

详情抽屉不显示原始正文，因为当前 `DocumentRead` 不返回正文。

## 文件导入衔接

文档页跳转：

```text
/import?library=<slug>&mode=add
```

`Import.js` 只做前端衔接：

- 读取路由 query。
- 当 query 中的 library 在用户可写库内时设为初始库。
- `mode` 只接受 `add` 或 `replace`。
- 非法或无权限参数回退到原有默认选择。

不修改导入 API 和上传队列逻辑。

## 前端数据边界

建议新增 `admin-ui/src/documents_ui.js`，只放无副作用纯函数：

- `documentType(row)`
- `documentDisplayName(row)`
- `documentStatusLabel(status)`
- `filterDocuments(rows, filters)`
- `paginateDocuments(rows, page, pageSize)`
- `formatDocumentTime(value)`

这些函数不导入 Vue、Element Plus 或 API，便于用 Node 行为测试覆盖筛选、类型识别和分页。

`Documents.js` 负责页面状态和 API 调用，不把筛选规则散落在模板中。

## 权限与错误处理

- read：查看列表、统计和详情。
- insert：提交文本、文件导入、编辑。
- delete：删除。
- superuser：在失败文档或失败任务上执行重试。
- 无可读知识库时不发送文档请求，并显示无权限/无可用知识库空状态。
- 文档任务加载失败只影响详情中的任务区，不关闭抽屉。
- 重试、编辑、删除完成后刷新列表和统计。
- 所有错误继续使用中文 `ElMessage`，不得直接展示 `[object Object]`。

## 明确不做

- 查看原文或下载原文件。
- 单文档分片数。
- 后端分页总数接口。
- 新增全文搜索接口。
- 文档正文版本历史。
- 普通用户重试管理员任务。
- 批量删除。

这些功能需要后端变化或风险明显增大，如后续需要必须先征得用户确认。

- 文件导入能带当前库跳转到现有导入页。
