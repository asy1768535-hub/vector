# 库管理页面重构设计

## 目标

参照 `D:\AI_work\job\向量库图片参考\库管理.png` 重构管理员“库管理”页面，使其与文档、用户、概览等已重构页面保持一致，同时不新增后端接口、不改变请求参数和权限行为。

## 页面结构

1. 顶部标题区：显示“知识库管理”、简短说明、“刷新”和“新建知识库”。
2. 筛选区：支持按名称或唯一 ID 搜索，并按状态、检索模式筛选；提供重置。
3. 统计区：从当前 `libs` 数组计算知识库总数、正常数量、OCR 开启数量、Rerank 配置数量，不发起额外请求。
4. 主表格：展示知识库名称与唯一 ID、状态、Embedding 配置、OCR/Rerank、检索模式、切分参数和操作。
5. 详情抽屉：点击行或“详情”后打开，展示描述、模型、维度、接口地址、Collection、全文源、切分参数等当前接口已有字段。

## 操作设计

- 表格直接保留“详情”“编辑”“常用问题”。
- “测试 Embedding”“重建 Collection”“删除”收进“更多”下拉菜单，减少操作列宽度。
- 已删除知识库继续禁用写操作，保留当前 `showDeleted` 行为。
- 新建、编辑、FAQ、测试、重建和删除继续调用现有 API，不新增假按钮。
- 新建和编辑弹窗按“基础信息”“向量与切分”“检索与处理”分区，保持现有字段、默认值、风险确认和差异提交逻辑。

## 数据与代码边界

- 新增 `admin-ui/src/libraries_ui.js`，仅承载筛选、统计、分页、状态文案和展示格式等纯函数。
- 修改 `admin-ui/src/views/Libraries.js`，保留 API 调用和业务行为，重构页面模板与交互状态。
- 修改 `admin-ui/style.css`，增加 `libraries-*` 样式并移除该页面内联样式。
- 新增 `admin-ui/libraries_redesign.test.mjs`，覆盖纯函数、API 保持、危险操作保护、无假字段和响应式结构。
- 复用现有 `dataEmpty`、本地图标组件和企业绿色主题，不新增图片素材或外部资源。

## 响应式

- `>=1200px`：筛选、统计、表格和右侧详情抽屉完整显示。
- `900–1199px`：统计保持四项，详情使用覆盖式抽屉，操作列收紧。
- `<900px`：筛选纵向排列，统计两列，表格保留受控横向滚动，弹窗宽度适配视口。

## 验收

- 页面不出现横向整页溢出，只有表格容器可横向滚动。
- 现有库管理 API、创建/编辑差异提交、FAQ、测试、重建和删除行为不变。
- 不展示接口不存在的文档数、更新时间、Rerank 模型等假数据。
- 手动刷新使用 `forceRefresh=true` 绕过缓存；写操作成功后继续依赖统一缓存失效。
- `node --test`、JS/MJS 语法检查和发布安全检查全部通过。
