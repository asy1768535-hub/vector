## 协作方式

- 用户负责把指令转发给实施智能体。
- 先检查现有代码和参考图，再制定指令；实施完成后必须独立验收，不能只相信智能体报告。
- 中文回复，文字简洁，但代码检查、测试和浏览器验证不能省略。
- 用户无法查看临时网页展示；需要视觉确认时使用参考图、真实页面测量或截图说明。
- 工作区存在大量未提交改动，禁止重置、覆盖或回滚无关文件。
