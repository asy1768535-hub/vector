## 2. Cause

The initial evaluation runner attempted to inject a disposable target URL through the in-process Alembic `Config`.
The repository Alembic environment then replaced that URL with `app.config.settings.db_dsn_sync`. As a result, the
configured application database, rather than the newly created disposable database, received migrations `0021`,
`0022`, and `0023`.

The corrective evaluator implementation now runs Alembic in a dedicated child process with target-database `DB_*`
values derived in memory from the validated disposable DSN. A disposable probe subsequently demonstrated a clean
`template0 -> 0023` upgrade, required core table presence, database cleanup, and live absence. This technical fix does
not retrospectively authorize the earlier configured-database change.
