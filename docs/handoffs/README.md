# 交接机制

本目录保存跨会话、跨智能体或阶段暂停时的**当前快照**。它不替代 `docs/AGENT_README.md`、活跃任务或测试输出。

## 何时创建

- 上下文即将结束，或另一位智能体接手；
- 当前任务未闭环但下一步已明确；
- 发布、部署、迁移或外部系统操作前后；
- 工作树存在足以让下一会话误判的未提交改动。

历史前端交接保留在 [`../agent-handoff.md`](../agent-handoff.md)，不把它当作当前全项目任务状态。

## 文件与命名

新文件名使用 `YYYY-MM-DD-<task-slug>.md`。同一任务只保留最近一份作为入口，旧交接文件不重写；在 `docs/AGENT_README.md` 的活跃任务段落链接最新文件。
